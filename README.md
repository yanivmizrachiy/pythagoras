## עריכת המלל — מצב עריכה מקומי

כלי פיתוח מקומי שמקל על עריכת הטקסט של 53 העמודים. **מקומי בלבד — לעולם לא נכלל בפרודקשן.**

```bash
npm start                 # מפעיל את שרת הפיתוח (http://localhost:8080)
```

פותחים כל עמוד עם `?edit=1`, למשל `http://localhost:8080/עמוד-9.html?edit=1`, ומקבלים:

- **ניווט לפי סדר החוברת** — בורר „עמוד N מתוך 53” בסרגל העליון קופץ ישר לעמוד הרצוי, בלי לנחש אילו שם קובץ (`עמוד-634`, `עמוד-9`…) שייך לאיזה עמוד.
- **עריכה במקום** — לוחצים על כל טקסט (כותרות, שאלות, הערות, פתרונות) וכותבים. הנוסחאות מוצגות כקוד `\(x\)` כדי שאפשר לערוך גם אותן.
- **שמירה בטוחה** — כפתור „שמור שינויים” (או `Ctrl+S`) מחליף אך ורק את הטקסט שנערך בקובץ המקור, שומר גיבוי `*.bak-<timestamp>` לצד הקובץ, ומדלג בבטחה על כל עריכה שאינה תואמת (לא דורס מבנה, SVG או נוסחאות).

העריכה כותבת ישירות לקובצי `עמוד-*.html` — לאחר עריכה מריצים `npm run validate` ומבצעים commit כרגיל.
